# ころころ星あつめ 🪐✨

スマホ縦画面向けのブラウザゲーム(β版)です。
かわいい惑星を画面中央の枠へ **外側から投げ入れて** 合体させ、はみ出さないように詰め込んでいきます。
**投げ入れた向きに枠内の重力方向が変わる** のが最大の特徴です。

[ゲームページ](https://shisoaqron.github.io/corocoro-planet/)

## ファイル構成
- `index.html` … UI骨格（上部UI / Canvas / 下部UI / チュートリアル・ゲームオーバー モーダル）
- `style.css` … かわいい宇宙・ネオン調テーマ、縦画面レスポンシブ
- `script.js` … 物理・投入・重力切替・合体・はみ出し判定・演出・サウンド
- `proto-images/` … 初稿イメージ図

## 遊び方
1. 画面を **タッチ（タップ）した位置** から惑星を投げ入れます。指は惑星をつかんでいる状態。
2. 投げたい向きへ **フリック（スマホ）／ドラッグ（PC）** して離すと、その向きへ飛んでいきます。
3. **ジェスチャの向き＝投げる向き＝枠内の重力方向**（任意の角度、ななめもOK）。
   - 右へフリック → 重力は右（星が右へ寄る）／ 上へフリック → 重力は上（星が上へ寄る）
   - ほぼ動かさずタップした場合は、枠の中心に向かって投げ入れます。
4. **同じ種類・同じ大きさ** の惑星どうしが触れると合体し、1段階大きな惑星になります。
5. 詰まりすぎると重力側の壁から少しずつ **はみ出し** ます。「ピンチ！」警告が出て、
   はみ出しが一定量を一定時間こえると **ゲームオーバー** です。

ローカルでは `index.html` を直接開くだけで動作します（サウンド初回は画面タップで有効化）。

## 1. 実装した仕様の要約
- **基本UI**：タイトル / SCORE / BEST / 現在の重力方向アイコン（上部）、説明文＋マスコット（下部）。
- **中央の枠**：Canvas にネオン調の角丸枠を描画。画面サイズに応じて中央に正方形配置。
- **次の惑星の表示**：枠の外周に「構え中の惑星」を表示。投入方向の矢印＋点線軌道のガイド付き。
- **外側からのドラッグ投入**：タッチ/マウス対応。ポインタ位置から最寄りの辺へ惑星を貼り付け、離すと内向きに発射。
  左・右・上・下のどの辺からも投入可能（仕様の必須2パターン「左から」「下から」を含む）。
- **投入方向に応じた重力切替**：投げた向き（4方位にスナップ）へ重力を変更。上部アイコンと枠中央の大きな矢印演出で可視化。
- **惑星の移動・接触**：位置ベースの緩和ソルバによる円同士の衝突。質量＝面積比で大きい惑星ほど動きにくい。
- **同種合体**：同段階が接触で合体→1段階上へ。合体エフェクト（弾けるパーティクル＋スコアポップ＋効果音＋軽いシェイク）。
  段階は **8種**（青小惑星 / 月 / 赤い惑星 / 縞惑星 / 土星 / 地球 / ガス惑星 / **ブラックホール**）。
- **ブラックホール（最終段階）**：ガス惑星×ガス惑星で誕生する特別な存在で、**ガス惑星より1〜2回り大きい**（衝突サイズ・巻き込み範囲・演出もこの大きさに連動）。
  誕生すると渦巻きながら **周囲の惑星を吸い寄せ**、約 `BH_LIFE` 秒後に **弾けて**、巻き込んだ惑星を消し去り **大量加点**します（巻き込んだ数×30＋100点）。
  詰まった盤面を一掃できる救済＆爽快ギミックです（ブラックホール同士は合体しません）。
- **隕石（お邪魔オブジェクト）**：いろんな方向から飛来し、**枠内に入るとその時の重力方向へ落ちる** 岩。
  顔なし・ボコボコの岩肌（4色パターン＋個体ごとにランダムな凹凸・クレーター・回転）。合体しない邪魔者で、盤面を圧迫します。
  ブラックホールの爆発に巻き込めば消せます。**デバッグ用に有無・頻度を調整可能**（下記）。
- **スコア加算**：合体段階に応じた得点。BEST は `localStorage` に保存。
- **はみ出しシステム**：壁を「やわらかく」し、混むと重力側へ押し込まれて枠外へバルジ。
  はみ出し量を正規化して合計した「危険度」で管理。
  - **警告状態**：危険度がしきい値を超えると「⚠️ ピンチ！ はみだしそう！」を表示（即アウトではない）。
  - **ゲームオーバー**：危険度が高い状態が一定時間継続、または一気に大きく超過した場合。
- **ゲームオーバー直前の見え方**：満杯時は惑星が壁際からはみ出し、警告が出て、次の惑星が外で構える構図になります（仕様6を満たす通常演出）。
- **リトライ**：ゲームオーバーモーダルの「もういちど」で即リスタート。
- **チュートリアル**：3枚（左から→重力右 / 下から→重力上 / 合体＆はみ出し注意）。`❓`からいつでも再表示。
- **演出**：合体パーティクル・スコアポップ・投入トレイル・画面シェイク・背景星のまたたき・簡易WebAudio効果音（`⚙️`でON/OFF）。
- **デザイン**：濃紺〜紫の宇宙背景、ネオンシアンの枠、表情つきデフォルメ惑星（目は重力方向を見る等の小ネタ）。
- **技術要件**：GitHub Pages 配置可・ローカルでも動作・タッチ/マウス対応・`localStorage` 保存・レスポンシブ・外部ライブラリ無し（フォントのみ任意でCDN、失敗時はsans-serifにフォールバック）。

## 2. 未実装・簡略化した点
- **物理は簡易近似**：流体や圧縮シミュレーションではなく、やわらかい壁＋緩和ソルバの近似。
  混雑時のはみ出しは「過拘束の残差＋最大はみ出し量クランプ」で表現しているため、厳密ではありません。
- **タッチした位置から投入**：惑星は指（タッチ位置）に追従し、そこから投げ入れる。ただし**枠の中からは投げられない**（枠内に入れると最寄りの辺の外側へ自動で押し出す）。
- **枠外への投げは許可・ただし減点**：枠に入らないまま画面外へ消えた投入は **減点（既定 -15点）**＋赤い「-15」ポップで通知。エイム中、枠に入らない向きのときはガイドが赤くなって予告。
- **重力方向は任意角度**：フリック／ドラッグの向き（開始点→離した点）をそのまま投げる向き＝重力方向に採用（ななめ可）。フリックの瞬間速度は投げる勢いに少し加味。ほぼ動かさないタップは枠の中心方向へ。
- **はみ出し判定の係数は手調整**：実機での体感に合わせて `WALL_SOFT` / `MAX_OUT_MUL` / `WARN_DANGER` / `OVER_DANGER` などの調整余地があります。
- **チュートリアルは絵文字＋簡易図**：proto-images 相当の専用イラストは未用意。
- **サウンドは簡易シンセ**：音声アセットは使わず WebAudio のビープで代用。
- **アクセシビリティ／多言語**：日本語のみ。色覚配慮などは未対応。

## 3. 今後の改善案
- 物理の作り込み：本物の圧力・連鎖崩れ・なめらかな沈み込みの表現。
- はみ出し演出の強化：はみ出した部分を枠外で半透明クリップ表示、ぷるぷる揺れ、回復時の吸い込み。
- 重力切替の演出：切替時に全惑星がふわっと流れるイージング、方向プレビュー。
- 段階ごとの専用イラスト・表情差分・合体時の固有エフェクト。
- スコア演出：コンボ／連鎖ボーナス、ハイスコア更新の派手な演出、ランキング。
- バランス調整：出現確率カーブ、枠サイズ可変モード、難易度（重力強度）選択。
- 操作改善：スワイプ軌道に応じた斜め投入、エイム中の着弾予測ライン。
- セーブ拡張：途中状態の保存、設定（音量・振動）保持、PWA化（オフライン対応・ホーム画面追加）。
- 演出強化：BGM、ハプティクス（バイブ）、パーティクルの質感向上。

## デバッグパネル（隕石の調整）
画面右側の **🛠 ボタン** で開閉できます。
- **隕石を出す**：ON/OFF
- **出現間隔**：1〜15秒（スライダー）
- **今すぐ1個 飛ばす**：手動で1個発生

コンソールからも調整できます。
```js
coroDebug.meteorsEnabled = false;  // 隕石を止める
coroDebug.meteorInterval = 3;      // 平均3秒間隔に
coroSpawnMeteor();                 // 今すぐ1個（プレイ中のみ）
```

## 調整ポイント（コード内定数）
`script.js` 冒頭の定数で挙動を調整できます。
- `GRAVITY` … 重力の強さ
- `WALL_SOFT` … 壁のやわらかさ（小さいほどはみ出しやすい）
- `MAX_OUT_MUL` … はみ出せる最大量（半径比）
- `WARN_DANGER` / `OVER_DANGER` / `OVER_TIME` … 警告・ゲームオーバーのしきい値
- `THROW_SPEED` / `THROW_COOLDOWN` … 投入の速さと連投間隔
- `DEBUG.meteorsEnabled` / `DEBUG.meteorInterval` … 隕石の有無・平均出現間隔
- `METEOR_SPEED` … 隕石の飛来速度（base比）／ `METEOR_STYLES` … 岩の色パターン
